v0.10.2 — Through the Door

The rest of the front door, and the crash that stood in it. A first-timer who runs `npx neat.is` now gets from the menu to a working graph without hitting anything the previous release still had in the way: a query verb finds the right project from the directory you're in instead of demanding `--project`; a stopped daemon comes back with `neat up`; a second project on the same machine no longer pauses the first; the header prints once; a killed run no longer leaves a lock that poisons every later one; and when a daemon fails to start you read its own log lines, not a timeout.

Behind it, the extractor stops carrying the source around. Every edge's evidence snippet used to hold the entire line it pointed at — for a minified bundle that is the whole file — and one such bundle under a gitignored Claude Code worktree turned a 63 MB repository into a gigabyte of JSON and a raw `RangeError`. Snippets are capped at the length the extraction contract always specified, the file walk honours `.gitignore` the way service discovery already did, minified files are read but not parsed, `.claude/` and `_next/` are never walked, and the snapshot is written as a stream. The same repository now produces a few megabytes.

## Highlights

- **Query verbs know where they are.** With no `--project`, a verb resolves the project from the directory (or its nearest registered ancestor) and talks to that project's daemon; a directory that isn't a project yet gets "run `npx neat.is` here first" and exit 2. With two repos, a verb from one no longer answers silently from the other's graph (#1157, #1179).
- **`neat up` starts or recovers the current project's daemon** and reports what it did. Query verbs stay read-only; their daemon-down message points at it (#1250).
- **Two projects run side by side.** A bare run in a new directory starts its own daemon and leaves the active one alone; the single-active rule is retired now that routing is per project (#1236).
- **One header.** A front-door run shows the wordmark and version once; the orchestrator it hands to skips its own banner (#1242).
- **A stale registry lock is reclaimed, not thrown**, and registry errors print their prefix once (#1241, #1240).
- **A daemon that fails to start shows its own log** — the last lines of `neat-out/daemon.log` inline, with the path (#1238).
- **Evidence snippets are capped** at the contract's ~120 characters in the one helper every extractor uses (#1254).
- **The file walk honours `.gitignore`, root and nested**, the way service discovery already did; ignored files are absent from the graph (#1255).
- **Minified files are read, not parsed** — a FileNode, no symbols, recorded as a skip (#1258).
- **`.claude/` and `_next/` are never walked**; the snapshot streams to disk and a snapshot that can't be written is reported in words (#1254).
- **The test suite can no longer touch your real `~/.neat`** — `NEAT_HOME` is set per test file before anything loads (#1244).
