v0.9.21 — Steady State

A hosted tenant now keeps its graph across restarts and reaches every GCP surface from one grant. When a daemon instance comes up fresh — after a redeploy, a scale-to-zero, a crash — it re-extracts every repository bound to it instead of trusting the control plane's memory that the last instance had already done so; the console pill shows `syncing` while it works. One Google consent fans out to Firebase, Cloud Run and the GCP Load Balancer on the daemon, with service names inferred from the graph where the provider's resource names don't match your package names. Push providers get their drain provisioned once and re-validated on restart, never duplicated.

`ask` learned to answer more of the questions people actually type — generic nouns, plain-English dependency phrasing, honest "no runtime yet" wording — and to keep weak matches out of the way of a clear one.

## Highlights

- **Bound repos re-extract on a fresh instance.** The first pass after boot syncs every bound repo regardless of the control plane's last status; later passes keep the incremental rule (#1216).
- **One GCP grant, three connectors.** A hosted `gcp` connection drives Firebase, Cloud Run and gcp-lb from a single credential source; Firebase leaves `cloud_run_revision` logs to Cloud Run so nothing double-counts; unmapped services are inferred from the graph (#1196).
- **Push providers provision through the same dispatch as the CLI.** A hosted Vercel connection provisions a drain once, records the handle beside the snapshot, and re-validates delivery on restart (#1191).
- **Local GCP connectors refresh their own token** from a service-account key through the connector refresh seam (#1188, ADR-230).
- **`ask` resolves generic node kinds** — "the database", "the service" — when exactly one exists, and lists candidates when several do (#1209).
- **`ask` understands dependency and runtime phrasing** — "talks to", "uses", "who depends on", "slow" — and documents the vocabulary (#1210).
- **`ask` says when runtime evidence is still missing** instead of counting divergences against a graph nothing has observed (#1204).
- **`ask` keeps weak cross-type matches out of the answer** beside a clear id match, and never lets a search hit outrank an explicit node (#1214).
- **Railway hosted options decode the composite project ref** on the daemon (#1178).
- **Deploy-mismatch divergences render in every surface** (#1173); MCP docs match the 24-tool manifest (#1180); the `neat init` summary reports static coverage per language (#1181).
- **The daemon routing model is recorded** — one daemon per project; `/projects/:project` is the legacy form (ADR-229, #1183).
