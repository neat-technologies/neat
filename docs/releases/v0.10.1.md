v0.10.1 — Front Door

A bare `npx neat.is` in a project that NEAT hasn't met yet now opens the front door every time: the wordmark, then a choice you move through with the arrow keys — log in to hosted NEAT, or self-host and take a copy-paste prompt for your coding agent — and then the flow you picked. It used to open exactly once per machine and never again; now it opens for every new project, stays out of the way for registered ones, and never interrupts a script.

The rest of the release is the hosted daemon and the Firestore extractor telling the truth in cases where they didn't. A hosted daemon re-lists its connections on a cadence, so a provider you connect after boot starts polling without a restart. Firestore calls made through a shared client — `export const db = getFirestore(app)`, imported everywhere, the layout every Firebase project uses — are now claimed, and the field guard has real columns to check instead of passing on nothing. The `firestore.rules` parser reads a denylist as a denylist: a negated `hasAny` no longer turns into a list of allowed fields, and a recursive wildcard no longer collapses onto a sibling key.

## Highlights

- **The front door opens for every new project.** The bare run gates on whether the current directory is already a NEAT project, not on whether this machine has ever logged in; the menu is navigable with ↑/↓ and Enter, with the numbered prompt as fallback where raw input isn't available (#1230).
- **The door asks before it writes.** Taking the local path asks once whether to instrument the services for OpenTelemetry now — it edits `package.json`, `requirements.txt` or `go.mod` and runs the package manager — with Enter as yes; `n` builds the declared side only and says how to add the runtime half later. An explicit `--no-instrument` is an answer, so the question isn't asked twice (#1233).
- **A colliding directory name is asked about, not errored on.** When the directory's basename is already a registered project, the door proposes the first free `<name>-N` and lets you type another; the run registers under the name you chose (#1239).
- **Ctrl-C at the door leaves quietly.** Interrupting the menu or a prompt exits with 130 and no stack trace — and no longer falls through into an extraction you just declined (#1232).
- **Logging in tells you where you stand, and what to do next.** The CLI's default control plane is `api.neat.is`. After a hosted login it checks whether the repository you're standing in is bound to the project: if it is, it says so with its sync status; if not, it offers to bind it through the console or shows the `neat sync --to` line that pushes your local graph. An account with no project yet is sent to onboarding and the CLI waits for the project to come up. It probes the project's daemon before ever saying "logged in", so a sleeping or broken tenant can't produce a false success (#1234).
- **A query against a stopped local daemon says how to bring it back.** The exit code and message are unchanged; one extra line names `neat <path>` as the recovery — only for a loopback daemon, since a hosted one isn't yours to start (#1250).
- **`neat init --help` answers.** `--help` is honoured after a verb as well as before one, across every command (#1243).
- **Hosted connections are re-listed on a cadence.** A connection added after the daemon started is picked up without a restart; unchanged connections keep their loops, changed ones restart, removed ones stop (#1217).
- **Firestore clients resolve across files.** A module that exports a Firestore client marks its importers' calls as Firestore calls; the field guard compares client-written fields against real columns (#1223).
- **`firestore.rules` denylists stay denylists.** Negated `hasAny`/`hasAll`/`hasOnly` clauses are not reducible to an allowlist and mark the collection indeterminate; `{document=**}` is not collapsed onto a sibling `{orgId}` (#1220).
- **Every package now declares Apache-2.0**, matching the `LICENSE` the code has always shipped under; earlier versions keep the stale field in their registry metadata, this one and everything after carry the right one (#1246).
- **An empty group in a Firebase service map is skipped** rather than mapped to nothing, and the GCP fan-out now carries its own test suite (#1208).
