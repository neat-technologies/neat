v0.10.6 — Attach and Observe

Instrumentation no longer edits your source. `npx neat.is` installs `@neat.is/otel-node` and starts the app with a `--require`/`--import` preload that stamps every outbound call with its file and line; Python gets `neat-otel` and a wrapped start command; Go keeps its generated additive file. The deps install so the app boots, and nothing in your tree changes. Editing source is still there behind an explicit `--source-edit`, and never from the front door. The preload reads the daemon's endpoint and token from the project itself, so a second attached project no longer goes dark, and the start recipe NEAT prints is one that runs. The preload also flushes its spans when the process exits on its own, so a script that runs once and quits still reports what it did, and it instruments postgres.js, with transactions, savepoints and reserved connections attributed to the connection they ran on. `@neat.is/otel-node` is the seventh package on the lockstep train.

An incident card now carries its own grade. From the card's own fields the daemon computes three gates (the policy verdict isn't block, the locus isn't a symptom alone, the locus resolves to code), eight weighted factors that each cite the fields they read, and a band — full, diagnose-only, or out — with the weights stated as priors on the card. A factor the card can't support is null with a reason, never a made-up number. The grade informs whoever reads the card; it rides beside the five-field incident stream, not inside it. The locus names the symbol, not the service.

The daemon sees more of what a failing system actually did. An OBSERVED error edge carries a bounded exemplar of the last error that crossed it. A Kubernetes workload that fails before its first span — a crash loop, a boot-time hang — gets its process log and its redacted env and args fused onto the incident, and when the runtime won't serve the previous instance's log (containerd under kind, or a process that retries forever and never terminates) the reader takes the current instance's instead.

A daemon can compute the pull-request verdict itself. `POST /pr-verdict` clones a base and a head commit shallowly, extracts each into a scratch graph that never joins a project, diffs them, reads the OBSERVED half from the live graph, and returns the same comment the GitHub Action posts — rendered by the Action's own module, so the two can't disagree. The hosted GitHub App posts that comment with no workflow file in the repository, and stamps its own marker rather than the Action's.

A daemon can also tell a remediation service about incidents without telling it anything about the source. `GET /incident-triggers` is a second event stream, behind its own bearer, carrying five fields per incident and no more; it replays from the project's incident ledger after `Last-Event-ID`, and the ledger is written before the trigger is published. `GET /graph` reports, per bound repository, whether its extracted source is at a verified commit, and a hosted daemon retries its boot sync per repository until that extraction completes. Symbols carry exact UTF-8 byte ranges beside their line spans.

The agent-facing copy — CLAUDE.md, the skill, the MCP tool descriptions, the front-door prompt — now says what NEAT is for: it does the investigation so the agent can write the code. The MCP server finds the daemon through the project registry the way the CLI does, a connection error names the recovery step, and the OTLP bearer header NEAT prints is one a collector will accept. The nightly channel waits for each package to become resolvable before publishing the next, so a nightly install can't race its own dependencies.

## Highlights

- **Attachment-first instrumentation** — `@neat.is/otel-node` (`--require`/`--import`), `neat-otel` (Python), no source edits by default; `--source-edit` is the gated fallback (ADR-232, #1292, #1296, #1298, #1300, #1303, #1306). Spans flush on natural exit (#1355); postgres.js is instrumented in the preload (#1356).
- **`IncidentCard.grade`** — gates, weighted factors with evidence, band and priors computed from the card by the daemon (ADR-238, #1350); the locus names the symbol (#1352); the band gates Sniper admission and nothing else (#1360).
- **OBSERVED error edges carry a last-error exemplar** (ADR-236, #1337).
- **Kubernetes process-log and env/args fusion** for workloads that fail before their first span (ADR-237, #1338), with a current-instance fallback where the previous log isn't served (ADR-239, #1361).
- **`POST /pr-verdict`** — the hosted PR comment is computed by the tenant daemon from the Action's own module (ADR-235, #1322, #1341).
- **`GET /incident-triggers`** — authenticated, incident-only event stream with ledger-backed replay (#1317, #1318, #1320).
- **`sourceBaselines` on `GET /graph`** — per-repository verified commit (#1313); hosted boot resync per repository (#1316).
- **Exact symbol byte ranges** — `span.startByte`/`span.endByte`, UTF-8, additive (ADR-234, #1315).
- **Agent guidance rewritten against the code and the thesis** — skill, MCP inventory, front-door prompt, CLAUDE.md (#1325–#1333, #1349).
- **OTLP bearer header percent-encoded** in printed setup (#1340); **nightly publishes wait for propagation** (#1358).
